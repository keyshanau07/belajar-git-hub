Belajar GIT 5 menit siap

  • 1. buat folder baru
  • 2. git init
  • 3. buat perubahan di file
  • 4. git add .
  • 5. git commit -m "pesan commit"
  • 6. buat repository di github
  • 7. git branch -M main
  • 8. git remote add origin https://github.com/username/repository.git
  • 9. git push -u origin main
